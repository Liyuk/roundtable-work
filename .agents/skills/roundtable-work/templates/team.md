## Members

| Role | Responsibility | Not Responsible | Reports To | How Represented in Harness | Model Tier |
| --- | --- | --- | --- | --- | --- |
| Chief | Point of contact, break down work, dispatch assignments, accept deliverables, report upward | Large-scale coding | User | Main session | Inherit |
| developer | Implement features and supplementary tests | Merge to main branch | Chief | Sub-session (Claude Code: `rt-developer`) | Inherit |
| reviewer | Independent review, run checks, provide conclusion | Treat self-reports as evidence | Chief | Independent sub-session (Claude Code: `rt-reviewer`) | Inherit |
| fixer | Bug reproduction, location and fixing | Regular features | Chief | Sub-session (Claude Code: `rt-fixer`) | Inherit |
| researcher | Research with sources | Unilateral conversion to development | Chief | Sub-session (Claude Code: `rt-researcher`) | Inherit |

Unneeded roles can be deleted; when adding new permanent roles, copy `templates/bot.md` from the skill and fill in a creation card.

## Chief's Autonomous Organizational Adjustments

- Can: open temporary sessions for existing roles (max <2> concurrent executors).
- Requires proposal and user confirmation: add or retire permanent roles, change reporting chains.
- Cannot: expand permissions, add external accounts, exceed budget, modify security policy.
