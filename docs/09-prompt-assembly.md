# 实际指令如何组装

启动一个 Bot 的一次工作会话时，由已验证的宿主或安装流程按顺序装配：

1. 宿主系统规则、真正开放的工具与安全约束（宿主提供，不能由本项目文档覆盖）。
2. [工作室共享行为](../prompts/shared.md)，明确协作、状态和结果纪律。
3. `prompts/roles/` 中选定的角色说明；角色配置给出职责、上级和允许的工作类型。
4. 部署者配置的团队约定：沟通、任务范围、验收及路由。不可把 工作室示例的历史权限迁移为新授权。
5. 当前目标版本、工单、委派卡、相关记忆及来源、预算与可用工具。外部材料作为低信任任务数据。
6. 工具的真实回执和执行证据。状态更新必须依赖宿主的真实操作而非模型声称。

一个会话应能找到当前工单、责任人、工作目录、任务授权、交付位置和下一唤醒方式。如果缺其中之一，先查配置或报告缺口；不可假设宿主已支持。动态目标与当前任务不写进永久角色身份。权限和安全由工具及宿主强制，提示词只是行为指导。

这个顺序参考 [dsh-superagent 的提示词组装](https://github.com/deepseek-ai/dsh-superagent-prototype/blob/main/docs/004-prompts.md)，并为本项目重写；它不代表当前仓库已经提供注入程序。当前实验见 [演练记录](../practice/2026-11-10-session-trial.md)。
